# 使用指南

[返回 README](../README.md)

Palbox 支持浏览器本地配置编辑和服务器管理两种模式。以下编辑操作适用于两种模式；本地模式将配置保存在浏览器中，管理模式将有效配置保存到服务器。

## 新建与导入

- 首次打开时创建「我的帕鲁世界」，使用内置的完整 122 项参数模板。模板是固定版本快照，不会联网自动更新。
- 可导入 `.ini` 文件，或粘贴包含 `OptionSettings=(...)` 的源码。每次导入创建独立配置，不会自动补入模板中的缺失字段。
- 支持新建、重命名、复制和删除配置。副本与原配置独立。

## 编辑参数

分类表单与「高级编辑」均可修改参数。参数同时显示原始名称和中文名称，可使用搜索框或按 `/` 搜索。

| 状态 | 含义 |
| --- | --- |
| 官方说明 | 有官方文档明确说明的参数 |
| 未验证 | 使用社区解释的参数 |
| 未识别参数 | 尚未收录用途说明的字段 |

悬浮在说明铭牌上可查看用途。当前模板包含 99 项有官方说明的参数和 23 项使用社区解释的参数，其中 11 项位于「高级设置」。来源保留在 [参数明细](parameters.md) 中，页面不展示来源链接。

点击顶部「未识别参数」统计卡片，或开启「仅显示未识别参数」，可以集中编辑未知字段。「仅显示未验证参数」用于筛选社区解释项。两种状态筛选互斥，可分别配合搜索使用。

搜索、分类和筛选不改变参数原始顺序、实际值或复制内容。原始文本值需要双引号，布尔值使用 `True` / `False`。

### 源码编辑

在「高级编辑 → 输入源码」中粘贴或编辑 INI，点击「应用源码」后同步到表单和输出，并自动保存。

「输出源码」只读展示当前生效的完整 INI，支持一键复制。未应用的输入和非法修改不会进入输出；切换输入与输出会保留输入草稿。解析失败时保留现有配置。

解析器拒绝重复目标段落、重复目标配置项、重复参数，以及未闭合的引号和括号。新版本未知参数和枚举可保留；导入时不强制重写旧配置，修改已知字段时才进行对应验证。

### 数值格式

显示、输出和复制共用小数格式，例如 `2` → `2.000000`、`2.5` → `2.500000`。更多小数位保留精度，整数参数和未知字段保留原样。

表单与参数列表加载时显示补齐后的值；输入期间保持光标位置，点击其他位置或按 Tab 离开输入框后补齐，并同步到当前编辑值。单纯查看已有配置不会产生修改。

## 保存与恢复

表单和参数列表的有效修改会自动保存，不会打断输入或重置光标。未应用源码和非法输入保留为当前页面草稿，不会写入已保存配置。

「本次修改」区域显示保存状态，悬浮可查看完整说明：

| 状态 | 含义 |
| --- | --- |
| 已保存 | 当前有效配置已存入对应存储 |
| 待应用 | 输入源码尚未应用到当前配置 |
| 输入有误 | 存在需要修正的输入 |
| 保存失败 | 存储失败，编辑结果仍保留在页面中 |

管理模式提交服务器时还会显示「保存中」。管理模式中的配置存盘与写入游戏是两个操作，游戏配置的「待生效」「已写入」「已生效」状态见 [Docker 部署文档](docker.md#配置与生效)。

保存失败时可先复制配置备份，按 `Ctrl/Cmd + S` 手动重试。切换配置时，如果仍有未应用源码、非法输入或保存失败的修改，会提示放弃或取消。

### 恢复输入配置

点击顶部「恢复输入配置」，确认后将当前配置恢复为最初输入或导入的完整内容，包含原始参数、未知字段、注释和顺序，并自动保存。

取消确认不会改变编辑。启用此功能前已有的配置，以当时已保存的内容为恢复基准；复制的配置以复制时的内容为独立基准。

### 本地数据

配置编辑模式将数据保存在当前浏览器、当前网站来源的 `localStorage` 中，不会上传。端口、域名、协议或浏览器不同，工作空间也不同。建议保持访问地址固定，并将重要配置复制为文件备份。

清除网站数据会删除本地记录。配置文件、本地存储和输入源码包含配置中填写的明文密码。

本地存储被禁用或空间不足时，页面显示失败信息，当前配置仍可复制。已有本地数据损坏时，页面保留原始数据、阻止覆盖，并提供临时工作空间。可先从浏览器开发者工具备份 `palbox.workspace.v1` 的原始值，再修复或移除该键并重新导入备份配置。

## 应用到游戏服务器

### 配置编辑模式

点击「复制配置」获取当前有效编辑结果。源码修改需要先点击「应用源码」，再复制输出。

先备份服务器原配置，将输出写入对应文件，然后重启游戏服务端：

| 系统 | 配置文件 |
| --- | --- |
| Linux | `Pal/Saved/Config/LinuxServer/PalWorldSettings.ini` |
| Windows | `Pal/Saved/Config/WindowsServer/PalWorldSettings.ini` |

修改 `DefaultPalWorldSettings.ini` 不会直接更新运行配置。参数行为与版本差异以 [帕鲁官方配置文档](https://docs.palworldgame.com/settings-and-operation/configuration/) 为准。

### 服务管理模式

点击「应用配置」，由管理后端完成校验、备份、写入，并按需重启游戏。仅保存面板配置不会直接修改游戏文件。操作流程与存档管理见 [Docker 部署文档](docker.md)。
