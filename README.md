# Palbox · 帕鲁配置工作台

中文、纯浏览器运行的 `PalWorldSettings.ini` 编辑器。支持多配置本地保存、常用参数表单、全部参数搜索与编辑、INI 源码编辑，以及文件选择、拖放和粘贴导入。

## 运行

使用 Node.js 22 或以上版本启动，无需安装依赖或构建：

```sh
npm start
```

访问 <http://127.0.0.1:8080>，按 `Ctrl+C` 停止。也可直接运行 `node server.cjs`。默认仅监听本机，修改端口可使用 `PORT=8081 npm start`（Linux/macOS）。

Node.js 使用内置 HTTP 模块提供页面和静态资源；所有配置编辑与存储仍在浏览器中完成。无需 Python 或第三方运行依赖。也可直接打开 `index.html` 或部署到静态文件服务器，推荐保持访问地址固定，让本地存储的来源保持稳定。

## 使用

1. 首次打开时创建「我的帕鲁世界」，使用本项目用户提供的完整 122 项参数模板。该模板是一个固定版本快照，不会联网自动更新。
2. 导入 `.ini` 文件或直接粘贴 `OptionSettings=(...)`。每次导入创建独立配置，不会补入缺失字段。
3. 在分类表单中调整常用参数；在「高级编辑」的参数列表中修改其他原始值。顶部「未识别参数」卡片显示当前文件中默认模板和参数说明均未收录的字段数量，点击即可集中查看和编辑；也可以在参数列表勾选「仅显示未识别参数」，并结合搜索筛选。默认模板的全部 122 项参数均算已识别，暂未提供中文控件的模板参数仍可在全部参数列表编辑。筛选不会删除或隐藏复制内容中的其他参数。文本原始值需要双引号，布尔值使用 `True` / `False`。
4. INI 源码编辑需点击「应用源码」再保存。解析失败保留现有配置；源码模式中的密码会以明文呈现。
5. 点击「保存配置」保存到当前浏览器，或按 `Ctrl/Cmd + S`。按 `/` 可搜索参数。
6. 点击橙色「复制配置」按钮，直接将完整 INI 内容复制到剪贴板，包含当前有效编辑结果。复制不会自动保存浏览器内的修改；源码修改需先应用。复制后可粘贴到服务器配置文件中，或自行保存为 INI 文件备份。

新建、重命名、复制和删除配置均在浏览器内进行。复制使用当前有效编辑结果，原配置保留其上一次保存的内容。切换配置时若有未保存修改，会提示放弃或取消。

数据保存在当前浏览器、当前网站来源的 `localStorage` 中，不会上传。端口、域名、协议或浏览器不同，工作空间也不同；直接打开本地文件时的存储行为取决于浏览器。配置文件和本地存储都包含配置中填写的密码。建议复制各配置并保存为文件备份；清除网站数据会删除本地记录。

若本地存储被禁用或空间不足，页面显示失败信息，当前配置仍可复制。若已有本地数据损坏，页面保留原始数据、阻止覆盖，并提供临时工作空间。可先从开发者工具备份 `palbox.workspace.v1` 的原始值，再修复或移除该键并重新导入备份配置。

## 应用到帕鲁服务器

先备份服务器原配置，再将复制的内容写入对应目录中的配置文件，并重启服务器：

- Linux：`Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`
- Windows：`Pal/Saved/Config/WindowsServer/PalWorldSettings.ini`

修改 `DefaultPalWorldSettings.ini` 不会直接更新运行配置。参数行为与版本差异以 [帕鲁官方配置文档](https://docs.palworldgame.com/settings-and-operation/configuration/) 为准；本工具不连接服务器，也不修改存档或 Mod 配置。

## 文件组织

- `js/template.js`：用户提供的默认配置模板。
- `js/schema.js`：中文字段说明、分类、控件类型和已知限制。
- `js/config.js`：INI/Unreal 元组解析与序列化；保留未编辑参数、未知参数及其他 INI 段落和注释。复制时将目标 `OptionSettings` 整理为单行。
- `js/storage.js`：本地工作空间格式与读写。
- `js/app.js`、`index.html`、`styles.css`：无框架界面与交互。
- `server.cjs`：使用 Node.js 内置模块的本地静态服务器，仅提供页面需要的资源。

解析器拒绝重复目标段落、重复目标配置项、重复参数以及未闭合的引号和括号。新版本的未知参数和枚举可保留；导入不强制重写旧配置，修改已知字段时才进行对应验证。

## 验证

运行核心配置与 Node.js 服务测试：

```sh
npm test
```

测试覆盖完整模板往返、仅更新指定字段、中文与转义字符串、空值、负数、嵌套列表、未知字段、BOM/换行、其他段落与注释、错误输入隔离、存储恢复、保存失败和 HTTP 静态资源访问。在浏览器访问 `/tests/index.html` 也可运行核心配置测试。

界面验收：分别在桌面和手机宽度检查分类、搜索、密码显示、表单与源码同步、配置复制隔离、删除确认、刷新恢复、未保存提醒和复制内容再导入。

另提供可选的 Playwright 自动化验收脚本 `tests/browser.cjs`。在可解析 `playwright` 包且已安装 Chromium 的环境中，启动上述静态服务器后运行 `node tests/browser.cjs`。可通过 `PALBOX_BASE_URL` 指定服务地址，`PALBOX_QA_OUTPUT` 指定截图与导入测试样例的输出目录（默认 `/tmp/palbox-qa-results`）。Playwright 只用于开发验收，网页不依赖它。
